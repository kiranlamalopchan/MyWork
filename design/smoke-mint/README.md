# Smoke-white background with mint surfaces

Light mode now uses a smoke-white page background (`#f5f5f5`), soft mint cards (`#edf7f1`) and green-tinted controls. These shared tokens generate the web stylesheet and native palette. Dark mode retains its black background; workplace Pay-card colours are preserved.

Validation: seven native theme/contrast tests, two backend palette checks and four JavaScript theme tests passed. Generated token parity and an automated mobile-width browser check passed. Screenshot shows the actual website login page. No installed mobile build was tested or deployed.
