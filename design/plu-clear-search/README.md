# Search-only PLU results

Supersedes the starter-item section shown in ../plu-usability/.

The initial results area is clear. Typing a query shows matching items; clearing the query removes them. Web checks also cover clearing a direct query URL and clearing while a real backend response is delayed.

Verified at 320px and 390px on the website and Expo browser renderer with real local catalogue data. Screenshots show the initial clear state; the native preview is not an installed app build. No runtime errors or horizontal overflow were found.

31 Django catalogue/navigation tests and five native search tests passed, along with TypeScript and JavaScript syntax checks. Changes remain local.
