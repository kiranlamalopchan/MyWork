# Minimal Profile

Profile now uses one centred portrait surface, a curved violet/pink accent, plain icon menu rows and a quiet sign-out action. Contact editing opens from My profile. Friends, Statement, Activity and Settings expand in place. Existing photo controls, account settings and permission-gated festival management remain available. Light and dark appearances share the layout.

Validation: 152 native tests and 55 account tests passed; TypeScript passed; lint has zero errors and the existing 24 warnings. iOS, Android and web Expo bundle export succeeded. Browser checks covered editing and settings on both implementations, all three native expandable panels, and the native layout at 320 px. Screenshots use a temporary empty preview account; native images show Expo's browser renderer. No signed mobile build, phone installation or deployment was performed.
