# Soft green Pay cards

Web and mobile Pay cards use the shared mint-to-sage wallet gradient with deep green text, extra-bold amounts, matching green selection dots and gold chips. All card text colours meet 4.5:1 contrast at the gradient endpoints.

Validation: 13 native Pay/theme tests, TypeScript, three backend Pay/palette checks, generated-file parity and whitespace checks passed. Automated Chrome checks verified both themes and workplace switching. Screenshots show the actual website using an isolated preview database. Native code was tested; no installed mobile build was tested or deployed.
