# Soft mint light mode

The shared light palette uses a pale mint page background (`#edf7f1`), white cards, green-tinted controls and emerald actions. Web, native UI, browser chrome, the web app manifest and administration reuse these roles. Workplace Pay-card gradients retain their identity colours. Dark page backgrounds remain pure black.

Validation: seven existing native theme/contrast tests, two backend palette checks and four JavaScript theme tests passed. Generated web/native files are current. Automated Chrome checks covered login, privacy and rules at 390 px, saved light preference overriding a dark system, browser chrome, white card surfaces and dark-mode black. No overflow or browser runtime errors. Screenshots show the actual website. No installed native build was tested or deployed; mobile requires rebuilding.
