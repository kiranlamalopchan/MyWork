# Festival banner scenes

The native banner replaces generic floating icons with drawn festival objects. Dashain has flying kites, a moving traditional swing and drifting marigolds; Tihar has glowing diyas and flowers; Holi has colour clouds; Eid has swaying lanterns; Buddha Jayanti has a lotus and petals; Krishna Janmashtami has a peacock feather and flute. Christmas, Easter, Nepali New Year, Lhosar, Chhath, Maghe Sankranti and Janai Purnima have their own related objects. The website's SVG scenes now have complementary objects and continuous animation too.

Animation loops run indefinitely while active, pause with the app/browser in the background, and retain still artwork for Reduce Motion. Native effects use a shared native animation clock with interaction handles disabled. The banner has a stronger readability scrim, warmer typography and a restrained story footer. Standard phone scenes remain 104 px high; longer greetings grow naturally instead of clipping.

Validation: 182 native tests, 18 backend festival tests and two JavaScript animation lifecycle tests passed. TypeScript passed; lint has zero errors and 24 existing warnings. iOS and Android bundle exports succeeded. Automated Chrome checks covered all 16 web festival variants, 320 px and desktop widths, a long custom greeting, Reduce Motion, and motion continuing beyond the first full cycle. No browser runtime errors occurred. Screenshots and the recording use an isolated preview database and the real website. No public festival configuration was changed. Native components were unit tested and bundled; no installed phone build was tested.
